# 📚 CourseHub – React Course Discovery Platform

A modern and responsive React.js web application to explore top online courses across different categories like Development, Business, Design, and Lifestyle.

---

## 🚀 Features

- 🔍 Browse courses by category
- ❤️ Like / Unlike courses
- 📦 Dynamic data rendering using API
- ⚡ Fast and responsive UI
- 🔄 Reusable components (Card, Cards)
- 🔔 Toast notifications for user actions

---

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- React Icons
- React Toastify
